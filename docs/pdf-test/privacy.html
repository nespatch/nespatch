Privacy

Last updated: November 21, 2026

Account

Sign-in uses Google. We store your account id and email so we can keep your credit balance. The balance is stored in Supabase.

Payment

Paddle.com processes the payment. We do not receive or store your card number. We receive a confirmation of the purchase so we can add credits. Read Paddle's privacy policy.

Files

The email typed for the translated file is stored in Supabase.

Analytics

The site uses PostHog to see which steps people finish. It receives a browser id and these steps: a visit, the languages, the sample slider, a one-page preview, the full-file payment page, that an email was saved, and a purchase. It does not receive the PDF, the file name, or the email address. When a file is chosen it receives the kind of PDF, the page count, and, once the price is calculated, the character count and the price. If a one-page preview fails, it receives the error text, cut to 200 characters.

A Google Ads tag loads on each visit. A completed purchase is also sent to Google Ads: the price and a transaction id. Google Ads does not receive the PDF or the card number.
